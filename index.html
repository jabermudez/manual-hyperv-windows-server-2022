Fundamentos

Qué vas a construir

Hyper‑V es la plataforma de virtualización de Microsoft. Permite ejecutar varios equipos virtuales aislados sobre un mismo equipo físico, compartiendo procesador, memoria, almacenamiento y red.

02
Antes de empezar

Requisitos del equipo anfitrión

Comprueba los requisitos antes de descargar archivos o crear la máquina virtual. Una preparación correcta evita la mayoría de los errores posteriores.

CPU

Procesador

64 bits, virtualización asistida por hardware y traducción de direcciones de segundo nivel (SLAT).

RAM

Memoria

8 GB como mínimo práctico; 16 GB o más recomendados para trabajar con comodidad.

SSD

Almacenamiento

Al menos 80 GB libres. Un SSD reduce de forma notable los tiempos de instalación.

OS

Sistema anfitrión

Windows 10/11 Pro, Enterprise o Education de 64 bits. Hyper‑V no está incluido en Home.

Comprobaciones rápidas

1

Abra Información del sistema

Presione Win + R, escriba msinfo32 y pulse Enter.

2

Revise los requisitos de Hyper‑V

Al final del resumen, las cuatro entradas de Hyper‑V deben indicar Sí.

3

Confirme la edición de Windows

Vaya a Configuración → Sistema → Acerca de → Especificaciones de Windows.

PowerShell · consulta del sistema
systeminfo.exe
Get-ComputerInfo | Select-Object WindowsProductName, WindowsVersion,
    CsTotalPhysicalMemory, HyperVisorPresent
!
Si la virtualización aparece deshabilitada

Reinicie el equipo, entre al firmware UEFI/BIOS y active Intel VT‑x/VT‑d o AMD‑V/SVM. El nombre exacto depende del fabricante.

03
Medio de instalación

Descargar Windows Server 2022

1

Obtenga la imagen oficial

Desde el Centro de Evaluación de Microsoft, seleccione Windows Server 2022 y descargue el archivo ISO de 64 bits.

2

Elija idioma y edición

Use el idioma que empleará durante las prácticas. En la instalación escogerá Standard o Datacenter y la modalidad con interfaz gráfica.

3

Guarde la ISO de forma ordenada

Ejemplo: D:\ISO\Windows_Server_2022.iso. Evite moverla después de asociarla a la VM.

4

Verifique la integridad

Calcule el hash SHA‑256 y compárelo con el valor publicado por el proveedor cuando esté disponible.

PowerShell · calcular SHA-256
Get-FileHash "D:\ISO\Windows_Server_2022.iso" -Algorithm SHA256
✓
Licenciamiento

La imagen de evaluación es adecuada para formación y laboratorios temporales. Para producción, utilice una licencia válida y respete los términos de Microsoft.

04
Plataforma de virtualización

Instalar Hyper‑V en Windows

Método gráfico

Características de Windows

  1. Abra el menú Inicio y busque Activar o desactivar las características de Windows.
  2. Marque Hyper‑V y confirme que incluye Plataforma de Hyper‑V y Herramientas de administración.
  3. Pulse Aceptar, espere la instalación y seleccione Reiniciar ahora.
  4. Después del reinicio, abra Administrador de Hyper‑V.
Método PowerShell

Instalación automatizada

Abra PowerShell como administrador y ejecute:

Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V -All

Confirme el reinicio cuando el sistema lo solicite.

!
Importante

Guarde su trabajo antes de habilitar la característica: el reinicio es necesario para cargar el hipervisor.

Verificación

PowerShell · estado de Hyper-V
Get-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All
Get-Service vmms

Debe ver: State = Enabled y el servicio vmms en estado Running.

05
Conectividad

Crear el conmutador virtual

El conmutador virtual funciona como un switch de red por software. Define con quién podrá comunicarse la máquina virtual.

EX

Externo

Conecta la VM con la red física e Internet mediante la tarjeta del host.

Recomendado para este laboratorio
IN

Interno

Comunicación entre el host y las VM, sin acceso directo a la red física.

Útil para redes aisladas
PR

Privado

Solo comunica máquinas virtuales conectadas al mismo conmutador.

Máximo aislamiento
1

Abra el Administrador de conmutadores virtuales

En Administrador de Hyper‑V, seleccione el host y, en Acciones, abra Administrador de conmutadores virtuales.

2

Cree un conmutador externo

Seleccione Externo → Crear conmutador virtual. Nombre sugerido: vSwitch-Externo.

3

Elija el adaptador físico correcto

Seleccione Ethernet o Wi‑Fi según la conexión activa. Mantenga marcada la opción que permite al sistema operativo de administración compartir el adaptador.

4

Aplique y espere

La conectividad del host puede interrumpirse unos segundos mientras Windows reorganiza los adaptadores.

Máquina virtual

Crear la VM para Windows Server 2022

NombreSRV-WS2022-LAB
Generación2
Procesadores2 vCPU
Memoria4–8 GB
Disco80 GB VHDX
RedvSwitch-Externo
i
Generación 2

Usa firmware UEFI, arranque seguro, controladora SCSI y dispositivos modernos. Es la opción recomendada para Windows Server 2022.

1

Inicie el asistente

Administrador de Hyper‑V → Nuevo → Máquina virtual. Revise la pantalla inicial y pulse Siguiente.

2

Nombre y ubicación

Escriba SRV-WS2022-LAB. Si dispone de otro disco SSD, marque la opción para almacenar la VM en una ubicación diferente.

3

Seleccione Generación 2

Esta elección no se puede cambiar después. Windows Server 2022 es compatible con UEFI y arranque seguro.

4

Asigne memoria

Use 4096 MB como mínimo práctico. Puede activar Memoria dinámica, dejando 4096 MB de inicio y un máximo acorde con el host.

5

Conecte la red

Seleccione vSwitch-Externo. Si aún no existe, puede dejar la VM sin conexión y asociarlo después.

6

Cree el disco virtual

Formato VHDX, expansión dinámica y 80 GB. El archivo crecerá según el espacio realmente utilizado.

7

Monte la imagen ISO

Seleccione Instalar un sistema operativo desde un archivo de imagen de arranque y busque la ISO descargada.

8

Finalice y ajuste

Antes de encender, abra Configuración → Procesador y asigne 2 procesadores virtuales. Confirme también firmware, DVD, disco y red.

Sistema operativo invitado

Instalar Windows Server 2022

ISOUEFISETUPSERVER
1

Conecte e inicie la VM

En Hyper‑V, seleccione la VM → Conectar → Iniciar. Cuando aparezca el mensaje, presione una tecla para arrancar desde el DVD virtual.

2

Defina idioma y teclado

Seleccione el idioma, formato regional y distribución de teclado correctos; luego pulse Instalar ahora.

3

Seleccione la edición con interfaz gráfica

Para un laboratorio de aprendizaje, elija Windows Server 2022 Standard Evaluation (Desktop Experience). “Server Core” no incluye escritorio completo.

4

Acepte la licencia

Lea los términos, marque la casilla de aceptación y continúe.

5

Elija instalación personalizada

Seleccione Personalizada: instalar solo Microsoft Server Operating System.

6

Seleccione el disco

Marque el espacio sin asignar del disco virtual y pulse Siguiente. El instalador creará las particiones necesarias.

7

Espere los reinicios

La VM copiará archivos y se reiniciará varias veces. No vuelva a presionar una tecla cuando aparezca el aviso de arranque desde DVD.

8

Establezca la contraseña

Configure una contraseña robusta para Administrator y guárdela de forma segura.

9

Inicie sesión

En la ventana de conexión use Acción → Ctrl+Alt+Supr, o el botón correspondiente, e ingrese con Administrator.

!
¿No inicia desde la ISO?

Apague la VM, revise Configuración → Firmware, confirme que la unidad DVD esté primero y que la ISO siga asociada.

08
Primer arranque

Configuración inicial del servidor

La instalación termina cuando el sistema arranca, pero el servidor aún necesita identidad, red, actualizaciones y seguridad básica.

01

Cambiar el nombre

Use un nombre descriptivo como SRV-DC01 o SRV-LAB01 y reinicie.

02

Configurar IPv4

Defina IP, máscara, puerta de enlace y DNS según el plan de direccionamiento.

03

Ajustar zona horaria

Use la zona local correcta; para Colombia: UTC‑05:00 Bogotá.

04

Actualizar

Instale las actualizaciones disponibles y reinicie cuando sea necesario.

05

Revisar red

El perfil, adaptador y DNS deben coincidir con el escenario del laboratorio.

06

Crear punto de control

Después de validar, cree un checkpoint llamado Base-Limpia.

PowerShell · configuración inicial de ejemplo
Rename-Computer -NewName "SRV-LAB01" -Restart

# Ejecutar después del reinicio; adapte nombres y direcciones
Get-NetAdapter
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.10.10 `
  -PrefixLength 24 -DefaultGateway 192.168.10.1
Set-DnsClientServerAddress -InterfaceAlias "Ethernet" `
  -ServerAddresses 192.168.10.1,1.1.1.1
!
No copie direcciones sin adaptarlas

La IP del ejemplo puede entrar en conflicto con su red. Use el direccionamiento asignado por el instructor o administrador.

Diagnóstico

Solución de problemas frecuentes

Hyper‑V no aparece en Características de Windows+

Compruebe que Windows sea Pro, Enterprise o Education y de 64 bits. Si es Home, deberá actualizar la edición o usar otra plataforma autorizada.

La máquina virtual no puede iniciar+

Revise que la virtualización esté activa en UEFI/BIOS, que Hyper‑V esté habilitado y que haya memoria disponible. Reduzca la RAM inicial si el host está limitado.

Aparece “No operating system was loaded”+

Confirme que la ISO esté montada, la unidad DVD sea la primera opción de firmware y que presionó una tecla durante el aviso de arranque.

La VM no tiene Internet+

Revise que el adaptador esté conectado al vSwitch externo correcto, que el host tenga conexión y que IP, puerta de enlace y DNS sean válidos. Pruebe primero gateway y luego DNS.

El host perdió temporalmente la red+

Al crear un conmutador externo, Windows reemplaza el enlace directo por un adaptador virtual. Espere unos segundos y confirme que se eligió la NIC física activa y que se permite compartirla con el host.

La instalación muestra solo consola+

Se instaló Server Core. Si necesita interfaz gráfica, repita la instalación y elija una edición que indique Desktop Experience.

El rendimiento es muy lento+

Cierre aplicaciones del host, use SSD, asigne 2 vCPU y al menos 4 GB de RAM, y evite reservar más memoria de la que el host puede sostener.

12
Administración eficiente

Crear el laboratorio con PowerShell

Este ejemplo reproduce la configuración base. Ejecútelo en PowerShell como administrador y adapte rutas, memoria y nombre del conmutador.

PowerShell · creación completa de la VM
$vmName = "SRV-WS2022-LAB"
$vmPath = "D:\Hyper-V"
$isoPath = "D:\ISO\Windows_Server_2022.iso"
$switchName = "vSwitch-Externo"

# Crear la máquina virtual de generación 2
New-VM -Name $vmName -Generation 2 -MemoryStartupBytes 4GB `
  -NewVHDPath "$vmPath\$vmName\$vmName.vhdx" -NewVHDSizeBytes 80GB `
  -Path $vmPath -SwitchName $switchName

# Ajustar procesador y memoria dinámica
Set-VMProcessor -VMName $vmName -Count 2
Set-VMMemory -VMName $vmName -DynamicMemoryEnabled $true `
  -MinimumBytes 2GB -StartupBytes 4GB -MaximumBytes 8GB

# Montar ISO y priorizar el DVD
Add-VMDvdDrive -VMName $vmName -Path $isoPath
$dvd = Get-VMDvdDrive -VMName $vmName
Set-VMFirmware -VMName $vmName -FirstBootDevice $dvd

# Iniciar
Start-VM -Name $vmName
VMConnect.exe localhost $vmName
!
Antes de ejecutar

Compruebe que las carpetas existen, la ISO es accesible y vSwitch-Externo coincide exactamente con el nombre de su conmutador.

Lista de verificación final

0 de 10 completadas

Seguridad

  • Use contraseñas únicas y robustas.
  • Aplique actualizaciones antes de instalar roles.
  • No exponga RDP directamente a Internet.

Rendimiento

  • No sobreasigne memoria o CPU.
  • Use almacenamiento SSD cuando sea posible.
  • Conserve espacio libre en el host.

Operación

  • Nombre VM, discos y switches de forma consistente.
  • Documente cambios de red.
  • No trate los checkpoints como copias de seguridad.

Capa que crea, ejecuta y aísla máquinas virtuales.
Host
Equipo físico que aporta los recursos de virtualización.
Guest
Sistema operativo que se ejecuta dentro de una VM.
VHDX
Formato moderno de disco duro virtual de Hyper‑V.
UEFI
Firmware moderno usado por las VM de generación 2.
Checkpoint
Punto de retorno temporal del estado de una VM.
